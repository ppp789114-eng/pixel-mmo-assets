# Pixel MMO Assets

Original pixel art for the Pixel MMO web client. The game code and art are kept in separate public repositories.

## Source and rights

Every image here was drawn from scratch for this project. No Ragnarok/RO3 files, copied sprites, third-party fonts, or traced artwork were used. Source notes and usage terms are in [ASSET-SOURCES.md](ASSET-SOURCES.md) and [LICENSE.md](LICENSE.md).
